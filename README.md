# greenhub

Генератор коммитов для таймлайна (contribution graph) профиля GitHub.
Работает в двух режимах:

- **без текста** — равномерно заполняет таймлайн случайным числом коммитов в день;
- **с текстом** — «рисует» коммитами заданный текст (`GH_TEXT`) на таймлайне.

## Как устроен таймлайн

Таймлайн GitHub — это сетка: **7 строк** (дни недели, сверху вниз: вс, пн, вт, ср, чт, пт, сб) и ~52 столбца (недели, слева направо). Один день = одна клетка. Чем больше коммитов в день, тем темнее клетка. Максимальная длина на год ~13 символов

Дата коммита берётся не из системных часов, а из переменных `GIT_AUTHOR_DATE` / `GIT_COMMITTER_DATE`, поэтому можно генерировать коммиты задним числом за любой период.

## Режим с текстом

Текст рендерится пиксельным шрифтом: каждый глиф — матрица клеток, где закрашенная клетка = день с коммитами.

- **Верхний регистр и цифры** — глифы **7×3** (7 дней × 3 недели): занимают всю высоту столбца, вс–сб.
- **Нижний регистр** — глифы **5×3** (5 дней × 3 недели): занимают строки пн–пт.
- **Между символами** — пустой столбец шириной в **1 неделю**.
- **Пробел** (между словами) — **2 недели**.

Поддерживаются только английские буквы и цифры. Итоговая ширина текста ограничена ~52 неделями — что не влезает, обрезается.

Алгоритм:

1. Текст переводится в битовую маску глифов шрифта.
2. Маска накладывается на календарную сетку, начиная с недели `GH_START_DATE` (дата выравнивается вперёд, на начало следующей недели, если не попадает на воскресенье).
3. Для каждой закрашенной клетки создаётся `GH_MAX_DAILY_COMMITS` коммитов соответствующей датой (максимальная яркость), для пустых — ничего.

## Режим без текста

Если `GH_TEXT` пуст, для каждого дня в диапазоне `GH_START_DATE`–`GH_END_DATE` создаётся случайное число коммитов от `GH_MIN_DAILY_COMMITS` до `GH_MAX_DAILY_COMMITS`.

## Содержимое коммитов

Каждый коммит меняет файл со сниппетом кода на случайном языке из `GH_LANGUAGES`, чтобы репозиторий выглядел живым и влиял на статистику языков профиля.

## Запуск

1. Скопировать `.dist.env` в `.env` и заполнить:

| Переменная | Описание |
| --- | --- |
| `GH_REPO` | Репозиторий, в который пишем коммиты |
| `GH_TOKEN` | Токен доступа к репозиторию |
| `GH_LANGUAGES` | Языки для генерируемых файлов, через запятую |
| `GH_MIN_DAILY_COMMITS` / `GH_MAX_DAILY_COMMITS` | Лимиты коммитов в день |
| `GH_START_DATE` / `GH_END_DATE` | Диапазон дат (ISO 8601) |
| `GH_TEXT` | Текст для отрисовки; пусто - режим без текста |

2. Собрать и запустить контейнер:

```bash
docker-compose up --build
```

## Ентрипоинт

- клонируем репо, если его нет локально;
- запускаем скрипт генерации.

## Работа скрипта

- проверяем, есть ли уже коммиты в день (не дублируем при повторном запуске);
- считаем целевое число коммитов на день (по маске текста или случайно);
- докоммичиваем недостающее с датой дня через `GIT_AUTHOR_DATE` / `GIT_COMMITTER_DATE`;
- пушим в `GH_REPO` с авторизацией по `GH_TOKEN`.

> Важно: чтобы коммиты попадали на таймлайн, email автора коммита должен совпадать с email аккаунта GitHub, а репозиторий должен быть публичным (или включён показ приватных контрибуций).
