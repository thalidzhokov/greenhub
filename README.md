# greenhub

Генератор коммитов для таймлайна (contribution graph) профиля GitHub с веб-интерфейсом.
Два режима:

- **заполнение** — случайное (или фиксированное) число коммитов в день в диапазоне дат, с фильтром по дням недели;
- **текст** — «рисует» коммитами заданный текст на таймлайне.

## Запуск

```bash
docker-compose up --build -d
```

Веб-интерфейс: <http://localhost:8087>

## Как пользоваться

1. Указать **URL репозитория** (https) и **токен**.
2. Выбрать **языки** — файлы-сниппеты этих языков попадут в коммиты.
3. Настроить **коммиты в день**: случайное число «от–до» (по умолчанию 1–5) или фиксированное (макс. 99).
4. Задать **дату начала** (по умолчанию год назад).
5. Выбрать вкладку:
   - **Заполнение** — дата окончания (по умолчанию сегодня) и дни недели;
   - **Текст** — строка из английских букв и цифр (до 1000 символов).
6. **Превью** — календарь активности в стиле GitHub, без обращения к репозиторию. Диапазон до года — один календарь; больше — отдельный календарь на каждый год.
7. **Пушим коммиты** — клонирует репозиторий, докоммичивает недостающее и пушит; прогресс виден в логе на странице.

### Токен

Нужен Personal Access Token (PAT):

- **Fine-grained** (рекомендуется): github.com/settings/personal-access-tokens → Generate new token; Repository access — Only select repositories; Permissions → Contents: Read and write.
- **Classic**: github.com/settings/tokens → scope `repo` (даёт доступ ко всем репозиториям сразу).

## Как устроен таймлайн

Таймлайн GitHub — сетка: **7 строк** (дни недели, сверху вниз: вс–сб) и ~52 столбца (недели). Один день = одна клетка; чем больше коммитов, тем темнее.

Дата коммита берётся из `GIT_AUTHOR_DATE` / `GIT_COMMITTER_DATE`, поэтому коммиты создаются задним числом за любой период (будущие даты отбрасываются).

## Режим с текстом

Текст рендерится пиксельным шрифтом (`glyphs.txt`):

- **верхний регистр и цифры** — глифы 7×3 (вся высота, вс–сб);
- **нижний регистр** — глифы 5×3 (строки пн–пт);
- между символами 1 неделя, между словами 2 недели;
- ~13 символов на год; длинный текст продолжается в следующие годы.

Маска накладывается на календарь с недели даты начала (дата выравнивается вперёд на воскресенье). Для каждой закрашенной клетки создаётся заданное число коммитов.

## Содержимое коммитов

Каждый коммит добавляет файл со сниппетом кода (`<ext>/<дата>_<номер>.<ext>`). Язык выбирается наименее заполненный из отмеченных — чтобы языки имели равный вес в статистике профиля. Сниппеты всех языков одного размера.

## Работа пуша

- клонируем репозиторий во временную папку;
- автор коммитов — имя и noreply-email владельца токена (через GitHub API);
- считаем уже существующие коммиты по датам — повторный запуск не дублирует;
- докоммичиваем недостающее и пушим партиями по 500 (GitHub индексирует не более ~1000 коммитов за пуш).

> Важно: чтобы коммиты попадали на таймлайн, email автора должен совпадать с email аккаунта GitHub, а репозиторий должен быть публичным (или включён показ приватных контрибуций).

## Структура

| Путь | Назначение |
| --- | --- |
| `greenhub/webapp.py` | Flask-приложение: UI, `/api/preview`, `/api/push`, `/api/jobs/<id>` |
| `greenhub/core.py` | планирование целей по дням и создание/пуш коммитов |
| `greenhub/font.py` | пиксельный шрифт: парсинг `glyphs.txt`, рендер текста |
| `greenhub/snippets.py` | реестр языков и сниппетов |
| `greenhub/templates/`, `greenhub/static/` | фронтенд |
| `snippets/` | файлы-сниппеты `example.<ext>` |
