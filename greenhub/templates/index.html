Какой репозиторий указать?

Лучше создать отдельный новый репозиторий на своём аккаунте — сюда будут заливаться сгенерированные коммиты, напр., https://github.com/thalidzhokov/greenhub-repo.git. Создать репозиторий можно по ссылке github.com/new.

Чтобы коммиты попадали на таймлайн, репозиторий должен быть публичным или в профиле включён показ приватных контрибуций.

Токен
Как получить токен?

Нужен Personal Access Token (PAT) — токен создаётся в настройках вашего аккаунта GitHub. Есть два варианта:

  1. Fine-grained PAT (рекомендуется): github.com/settings/personal-access-tokens → Generate new token. Настройки:
    • Repository access — Only select repositories, выбрать репозиторий для коммитов (напр., greenhub-repo);
    • Permissions → Repository permissions → Contents: Read and write — это единственное нужное разрешение.
  2. Classic PAT: github.com/settings/tokens → Generate new token (classic) → scope repo. Минус — даёт доступ ко всем вашим репозиториям сразу.

          Подробнее о том, как GitHub определяет языки, можно узнать по ссылке
          github-language-support.
