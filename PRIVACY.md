# Политика конфиденциальности greenhub

Последнее обновление: 13 августа 2026

greenhub — самостоятельно разворачиваемый (self-hosted) инструмент: всё приложение
работает в Docker-контейнере на вашей машине. У greenhub нет собственного сервера,
внешней базы данных, аналитики и телеметрии. Никакие данные не передаются
разработчикам greenhub или третьим лицам.

## Какие данные обрабатывает приложение

| Данные | Откуда | Зачем |
| --- | --- | --- |
| URL репозитория | вводите в форме | клонирование и пуш сгенерированных коммитов |
| Personal Access Token (PAT) | вводите в форме | авторизация git-операций и запрос к GitHub API |
| Имя, логин, id аккаунта GitHub | GitHub API (`/user`) | подстановка автора коммитов (имя и noreply-email), чтобы коммиты попадали на таймлайн |
| Параметры генерации (языки, даты, текст и т. п.) | вводите в форме | построение плана коммитов |

## Где и как данные хранятся

- **В браузере.** Значения формы, включая URL репозитория и токен, сохраняются в
  `localStorage` вашего браузера в открытом виде — чтобы форма переживала обновление
  страницы. Данные не покидают браузер; очистить их можно, удалив данные сайта в
  настройках браузера.
- **В контейнере.** Логи задач (проверка, очистка, пуш) держатся в памяти процесса и
  исчезают при перезапуске контейнера. Токен в текстах ошибок затирается (`***`).
  Клон репозитория создаётся во временной папке и удаляется по завершении задачи.
- **Постоянного серверного хранилища нет.** Приложение ничего не пишет на диск,
  кроме временного клона на время выполнения задачи.

## Куда данные передаются

Единственный внешний сервис, с которым взаимодействует приложение, — **GitHub**:

- `https://api.github.com/user` — получение имени и id владельца токена;
- git-операции (`clone`, `push`, `ls-remote`) с указанным вами репозиторием,
  авторизованные вашим токеном по HTTPS.

Больше никаких сетевых запросов приложение не делает.

## Ваша ответственность

- Используйте fine-grained PAT с минимальными правами (Contents: Read and write,
  только для выбранного репозитория) — см. подсказку у поля токена.
- Не разворачивайте приложение на общедоступном хосте без дополнительной защиты:
  веб-интерфейс не имеет аутентификации, а токен хранится в localStorage браузера.
- Токен можно отозвать в любой момент в настройках GitHub
  ([github.com/settings/tokens](https://github.com/settings/tokens)).

## Изменения политики

Политика может обновляться вместе с функциональностью приложения. Актуальная версия
всегда находится в этом файле в репозитории проекта.
